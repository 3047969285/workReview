# 安全作业承载力分析

拿到本技能后**直接跑下面这一条命令**。不要先打开 references、不要先通读脚本。references 只在要改公式或字段口径时再查。

`<技能>` = 本文件所在目录的绝对路径。

## 立刻执行

用户没上传计划文件时，数据源固定为 `<技能>/data/工作计划-测试数据.xls`。所属机构默认 `国网青岛供电公司安全生产委员会办公室`，只有用户改口才换 `--office`。

出日 + 周 + 月（把 `YYYY-MM-DD` 换成用户给的锚定日；没给就用 `2026-09-01`）：

```bash
python "<技能>/scripts/runReports.py" \
  --source "<技能>/data/工作计划-测试数据.xls" \
  --all \
  --report-date YYYY-MM-DD \
  --advice "<技能>/承载力报告/建议/advice_20260901.json" \
  --office "国网青岛供电公司安全生产委员会办公室" \
  --out-dir "<技能>/承载力报告" \
  --chart native
```

用户上传了 `.xls` / `.xlsx` 时，只把 `--source` 换成该文件的绝对路径，其余不变。

成品在 `<技能>/承载力报告/承载力报告{当天YYYYMMDD}/`，三份 `.docx`：

- `国网青岛供电公司2026年M月D日安全承载力分析报告.docx`
- `国网青岛供电公司2026年M月份第N周安全承载力分析报告.docx`
- `国网青岛供电公司2026年M月份安全承载力分析报告.docx`

只出一份时把 `--all` 换成 `--template 报告-日` 或 `报告-周` 或 `报告-月`。`--advice` 文件要带上本次模板对应的键；正文不抄这个 JSON，建议章由计算数字生成。

## 版式（代码已固化，不要手改成品）

- 报告里独立成段的「注：…」会删掉。不删正常数据。
- 表不拆「续表」。每一列大约两个汉字宽，多出来的字在格子里换行。
- 图是 Word 可编辑的 DrawingML（`c:chart`），不是只贴 PNG。分类轴和数值轴 `crosses=min`，交于同一原点。纵轴单位标题 `overlay=0`，不用 `manualLayout` 把单位挪开。
- 月报每一周单独一页，周标题和当周图表、评述在同一页。

## 不要改的计算口径

- θ：工作内容或作业类型去空白后正好是「装表接电」时取 0.2。
- β：配置「强制统一β」在 `parse_person` 读取。当前 true，每人用默认 1.0；false 时用人员档案「作业素养能力」。
- 班组公式按人员档案「班组类型」。多班组名称写成「班组名-人数」。
- 「电网风险等级」不参与计算。风险只用「作业风险等级」。
- 周报标题日期不带全角括号。月报各周标题仍保留括号。
- 建议章只来自 `genReportParams._advice_from_numbers`。
- 预警只有轻载 / 适度 / 重载 / 满载。超过 100% 仍是满载。没有停工档。

| `references/作业计划数据字段说明.md` | 改列映射 |
