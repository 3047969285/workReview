# 报告模板字段说明（.doc 官方模板 + 一句话生成映射）

> 本文档说明 `templates/` 下 6 份官方公文模板(.doc)的占位符字段,以及如何用 `scripts/fillReport.py` 把承载力计算结果填充成成品报告 / 函件。**填充时模板只读、不得用成品覆盖原文件**。月报图序：图1 概况作业类型、图2 全月作业、图3 全月管理，其后每周作业/管理。

## 1. 六份模板一览

| --template 取值 | 模板文件 | 用途 | 触发场景 |
|---|---|---|---|
| `警示函-满载` | `安全风险警示函-（XX单位XX时间承载力满载）.doc` | 安全风险警示函 | 单位承载力满载 >90% |
| `提示函-重载` | `安全风险提示函（XX单位XX时间承载力重载）.doc` | 安全风险提示函 | 单位承载力重载 >75% |
| `提示函-长期作业` | `安全风险提示函（XX单位XXX长期作业）.doc` | 安全风险提示函(长期作业) | 工作负责人连续作业超限 |
| `报告-日` | `国网青岛供电公司2026年X月X日安全承载力分析报告.doc` | 日承载力分析报告 | 按日 |
| `报告-周` | `国网青岛供电公司2026年X月份第X周安全承载力分析报告.doc` | 周承载力分析报告(周报) | 按周 |
| `报告-月` | `国网青岛供电公司2026年X月份安全承载力分析报告.doc` | 月度承载力分析报告(月报) | 按月 |

## 2. 模板占位符字段

模板正文、标题、附表内含两类占位符:

### 2.1 日期 / 编号类(函件与报告共有)

| 占位符 | 示例替换 | 说明 |
|---|---|---|
| `20××年××月××日至××月××日` | `2026年9月1日至9月5日` | 统计区间(函件正文) |
| `20××年第×周（20××年××月××日至××月××日）` | `2026年第36周（2026年9月1日至9月5日）` | 周次+区间 |
| `20××年××月××日` | `2026年9月3日` | 单日 |
| `20××年第××号` | `2026年第36号` | 文号 |
| `××月××日` | `9月5日` | 短日期 |
| `2026年X月X日` | `2026年9月3日` | 日报告标题 |
| `X月份第X周（X月X日至X日）` | 周报:`9月份第1周8月31日至9月6日`(去掉全角括号)。月报各周标题仍保留括号,如 `9月份第1周（8月31日至9月6日）` | 周报副标题 / 月报周标题 |
| `X月X日至X日（X天）` | `9月1日至6日（6天）` | 周报告区间+天数 |
| `X月份` | `9月份` | 月报告标题 |

### 2.2 单位 / 作业 / 数量类(注意先长后短替换)

| 占位符 | 示例替换 | 说明 |
|---|---|---|
| `××公司××工区工作负责人×××连续工作超××天` | `青岛公司变电检修工区工作负责人王**连续工作超5天` | 长期作业函主题句 |
| `××公司××工区` | `青岛公司变电检修工区` | 警示函单位 |
| `××公司××中心` | `青岛公司配电运检中心` | 提示函/重载函单位 |
| `××单位` | `变电检修中心` | 普遍性单位占位 |
| `X1` / `X2` / `XX1` / `XX2` | `变电检修中心` / `输电中心` / `市南中心` / `电缆中心` | 附表单位列;**必须长键(XX1)先于短键(X1)替换**,否则 XX1 会被拆成 X+变电检修中心 |
| `XXXXX等工作` | `日常工作` | 作业内容占位 |
| `共安排日计划X项` | `共安排日计划12项` | 日计划数量 |
| `二级风险作业X项` | `二级风险作业1项` | 二级风险项数 |
| `三级风险作业X项` | `三级风险作业3项` | 三级风险项数 |

> **填报单位清单(周报矩阵表表头,模板固有)**:变电运维、变电检修、输电中心、带电中心、电缆中心、市南中心、市北中心、崂山中心、李沧中心、城阳中心、安装公司、送变电、胶州公司、即墨公司、黄岛公司、平度公司、莱西公司。

### 2.3 辅助建议占位符（三份报告模板文末「四、辅助建议」章）

| 占位符 | 说明 |
|---|---|
| `ADVICE_BODY_2026` | 三份报告文末「四、辅助建议与风险管控提示」的占位壳是 `（本期辅助建议由研判人员结合承载力数据综合提出。建议占位符：ADVICE_BODY_2026）`。`genReportParams._advice_from_numbers` 用这次算出的项数、居前单位及百分比、峰值语气(满载/重载/适中/轻载)和管理承载力百分比写成一句,整段替换这个壳。二级或三级为 0 的分句省略。没有三级及以上明细时,概况句为「当日/本周/当月三级及以上风险作业不单列明细。」。`--advice` 仍可能被 CLI 校验要求存在,`DEFAULT_ADVICE` 留作兼容;JSON 自由正文不写入 `KEY_ADVICE_BODY`。 |

> 建议章数字和单位必须来自当次计算。AI 可以审读生成句,不要另写一段 advice JSON 散文当作报告正文。`--advice` 与 `--office` 的 CLI 要求见 `SKILL.md` 工作流第 0 步和第 5 步。

## 3. fillReport.py 用法

```bash
# 列出模板
python scripts/fillReport.py --list

# 演示(内置示例参数,验证模板链路)
python scripts/fillReport.py --demo --template 报告-周 --out 成品.doc

# 正式填充
python scripts/fillReport.py --template 报告-周 --params params.json --out 成品.doc
```

`params.json` 结构:

```json
{
  "replace": {
    "X1": "变电检修中心",
    "XX1": "市南中心",
    "共安排日计划X项": "共安排日计划12项"
  },
  "tables": [
    {
      "columns": ["日期", "变电运维", "变电检修"],
      "rows": [["1日", 40, 55], ["2日", 30, 120]]
    }
  ]
}
```

- `replace`:全文(标题+正文+表格单元格)键值替换;**键按长度降序处理(先长后短)**,防止 `X1` 误伤 `XX1`。请勿在 value 中再放入会被后续键命中的文本。
- `tables`:按表头列名定位目标附表(多表并存时按匹配度取最优),清空示例行后按数据行重填;`rows` 与 `columns` 一一对应。
- 退出码同 calcCapacity:0=成功 2=用法错误 3=输入数据错误 4=文件/IO 错误 1=未知异常。

## 4. 版本限制与注意

- 依赖 pywin32(Word COM),Windows + 已装 Office/WPS 环境。内网部署步骤见 `环境部署与Python安装说明.md`。
- 模板一律 `ReadOnly` 打开、`SaveChanges=False` 关闭,**不写回模板**。
- 成品默认按扩展名判定格式:`.doc` 存老格式,`.docx` 存新格式。
- 报告内姓名一律输出真名(不脱敏,配置 `输出姓名脱敏=false`、`MASK_NAMES=False`);身份证号/联系方式/地址等敏感字段不得进入模板与成品。

## 5. 「一句话 → 参数」映射(供 Dify 编排 / 智能体链路)

由用户一句话 + 承载力计算结果决定选模板并组 params:

| 用户诉求模板句 | 选模板 | replace 组装 | tables 组装 |
|---|---|---|---|
| 「XX中心承载力满载了,发个警示函」 | `警示函-满载` | 日期序列、文号、`××公司××工区`、`××单位` | 高风险作业明细表 |
| 「XX单位重载了,发个提示函」 | `提示函-重载` | 日期序列、文号、`××公司××中心`、`××单位` | 高风险作业明细表 |
| 「某工作负责人连续作业超限,提示去休息」 | `提示函-长期作业` | `××公司××工区工作负责人×××连续工作超××天`、区间日期 | (如有明细填表) |
| 「出日承载力报告:X月X日」 | `报告-日` | `2026年X月X日`、日期序列、计划/风险项数 | 高风险作业明细表 |
| 「出周承载力报告:某月第X周」 | `报告-周` | 标题键、`X月X日至X日（X天）`、计划/风险项数 | 明细表 + 「日期×单位」矩阵热表 |
| 「出月度承载力报告:某月」 | `报告-月` | `X月份`、日期序列、计划/风险项数 | 高风险作业明细表 |

自动化路径:calcCapacity.py 产出承载力 JSON → 依据预警分级(满载>90% / 重载>75%)与周期选取模板 → 由计算结果生成 replace/tables 参数 → 调 fillReport.py 落成成品 Word。
