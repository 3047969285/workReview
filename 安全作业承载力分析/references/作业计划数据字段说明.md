# 作业计划数据字段说明

> 输入数据以《青岛工作计划信息导入模板-秋检.xls》的「秋检计划」表为基准。计算读取作业计划、人员档案、组织架构。秋检计划表没有身份证号列,也没有人员姓名列。「工作负责人」是人数。请假不从 Excel 读入,只在规范化 JSON 的 `absence` 中扣减。非敏感字段示例见文末。

## 1. 作业计划表(31 字段,"工程项目信息"工作表)

| 序号 | 字段 | 说明 | 计算用途 |
|---|---|---|---|
| 1 | 序号 | 行号 | — |
| 2 | 工程名称 | 与立项项目名称一致 | — |
| 3 | 金额(万元) | 项目总金额 | — |
| 4 | 作业类型 | 下拉:输变电工程/技改/大修/常规检修等 | 去空白后正好是「装表接电」时 θ=0.2 |
| 5 | 单体工程 | 如"农灌用电配套" | — |

| 7 | 电压等级 | 1000kV/750kV… | — |

## 3. 人员档案最小字段(测算 β 用)

| 字段 | 说明 |
|---|---|
| 人员姓名 | 输出真名(不脱敏) |
| 所属班组 | 班组层级 |
| 是否工作负责人 | 是/否 |
| 人员效能系数 β | 配置「强制统一β」当前为 true 时不读这一列,每人用默认 1.0;改为 false 后读取「作业素养能力」,缺省 1.0 |
| 班组类型 | 检修施工 / 运检合一 / 变电运维 / 调控。驱动班组公式;没填或并列时回退「默认班组类型」(当前检修施工)。调控走检修施工分支 |

> 管理承载力附加可选列（人员档案表，缺失时按默认值回退）：
> - **县公司 / 单位（工区）**：把人员归到报告 17 单位列（工区优先、县公司兜底），用于统计“在家管理人员数”。
> - **职务**：与 是否工作负责人(角色) 列拼接后，命中「管理岗关键字」（管理/主任/副主任/书记/经理/专责…）者计入管理人员。

## 4. 请假 / 出差信息

Excel 作业计划路径**不加载**请假表,`excelLoader` 传出的 `absence` 为空,因此 Excel 来源不会做请假扣减。只有规范化 JSON 里的 `absence` 会在当日分母中减去不在岗人员的 β。

| 字段 | 说明 |
|---|---|
| 人员姓名 | 与人员档案姓名对应 |
| 所属班组 | 计算扣除 N |
| 不在岗类型 | 请假/出差/参会/培训 |
| 起止时间 | 影响哪些日期的分母 |

## 5. 组织架构

公司 → 工区(专业) → 班组 → 人员的层级树,用于逐级聚合与权重计算。
