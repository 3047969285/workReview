> 输入数据以《青岛工作计划信息导入模板-秋检.xls》为基准。承载力量化所需核心数据:作业计划、人员档案与效能、请假/出差、组织架构。非敏感字段示例见文末。

## 3. 人员档案最小字段(测算 β 用)

| 字段 | 说明 |
|---|---|
| 人员姓名 | 输出真名(不脱敏) |
| 所属班组 | 班组层级 |
| 是否工作负责人 | 是/否 |
| 人员效能系数 β | 单值参数,由数据源直接给定;缺省 1.0 |

> 管理承载力附加可选列（人员档案表，缺失时按默认值回退）：
> - **县公司 / 单位（工区）**：把人员归到报告 17 单位列（工区优先、县公司兜底），用于统计“在家管理人员数”。
> - **职务**：与 是否工作负责人(角色) 列拼接后，命中「管理岗关键字」（管理/主任/副主任/书记/经理/专责…）者计入管理人员。

## 4. 请假 / 出差信息

| 字段 | 说明 |
|---|---|
| 人员姓名 | 输出真名(不脱敏) |
| 所属班组 | 计算扣除 N |
| 不在岗类型 | 请假/出差/参会/培训 |
| 起止时间 | 影响哪些日期的分母 |

## 5. 组织架构

公司 → 工区(专业) → 班组 → 人员的层级树,用于逐级聚合与权重计算。
