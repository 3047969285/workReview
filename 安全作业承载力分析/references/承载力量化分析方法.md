# 安全承载力量化分析方法(公式与口径)

> 依据《安全承载力量化分析方法》。承载力测算以"人"为承载基础、以"作业班组日承载力"为最小单元,综合考影响安全的各项要素加权赋值。
> 以工作负责人、班组成员承载力为首要判定条件,任一条件超红线时统筹调配作业计划;满足条件时再对班组、工区逐级量化评价。

## 1. 人员效能折算系数 β(单参数)

人员效能折算系数 β 为**单值参数**,由基础数据源直接给定(每名人员一个 β 值),不再拆分年龄、学历、技能、专家、能级、熟练度、素养、绩效等明细逐项折算。

> 人员档案为**必要数据源**(Excel 一律加载):班组可用人数、工作负责人真名、各级在册人数均取自此;β 仍由「强制统一β」开关控制(当前 true,统一按 **1.0**、按人数计),置 false 后逐人读取档案 `beta` 字段。以下公式中的 β 均按当前口径。

| 项 | 取值 |
|---|---|
| β 来源 | 人员档案字段 `beta`(人均一个数值) |
| 缺省 | 1.0(字段缺失时按 1.0 计) |
| 当前口径 | 「强制统一β」=true → 统一 1.0 按人数计;置 false 后逐人取值 |
| 人员档案 | 必要数据源,一律加载(真实分母/负责人真名);计划匹配不到档案整条剔除 |

以下各承载力公式中的 β_j(作业负责人)、β_i(人员)一律取该单值参数。

## 2. 作业风险系数 θ

| 作业风险等级 | 二级 | 三级 | 四级 | 五级 | 装表接电 |
|---|---|---|---|---|---|
| θ | 1.5 | 1.2 | 1.0 | 0.8 | 0.2 |

## 3. 日承载力测算(标准工时 8 小时/天)

> 作业时长 T:不足 1 小时按 1 小时计,超过 8 小时按 8 小时计。

### 3.1 工作负责人承载力(k 级及以上风险)

```
F_k^负责人 = Σ(j=1..n_k)(T_j·θ_j·β_j) / [8 · Σ(i=1..N_k) β_i]
F_负责人 = max{ F_2, F_3, F_4, F_5 }
```

- n_k:当日 k 级及以上风险作业数量
- N_k:班组可承担 k 级及以上风险工作的负责人总数
- β_j:该项工作负责人的效能折算系数

### 3.2 班组成员承载力

通用分母:`8 · (Σ(i=1..M)β_i − Σ(i=1..N)β_i)`
M=班组员工总人数;N=请假(出差、参会、培训等不在岗)人数。

- **检修、施工作业型**:`F = Σ(j=1..n){T_j·θ_j·Σ(i=1..m_j)β_i} / 分母`(m_j 为第 j 作业组作业人数)
- **倒闸操作(变电运维)**:`F = Σ(j=1..n){T_j·Σ(i=1..m_j)β_i} / 分母`
- **巡视类**:`F = Σ(j=1..n){T_j·Σ(i=1..m_j)β_i} / 分母`
- **调度、供服班组**:`F = 当值操作/许可/报表等所需标准人工时 / 当值总人工时`

### 3.3 班组日承载力

| 班组类型 | 计算公式 |
|---|---|
| 检修、施工作业型 | F = max{F_负责人, F_检修施工} |
| 运检合一型 | F = max{F_负责人, F_检修施工} + F_巡视 |
| 变电运维型 | F = F_倒闸操作 + F_巡视 |

### 3.4 工区(专业)承载力

```
F_工区 = Σ(i=1..N) k_i · F_i
k_i = F_i / Σ(i=1..N)F_i      (第 i 个班组权重为自身承载力占比)
```

### 3.5 管理承载力

```
F_管理 = 实需人天 / (单位全部在册可用人数 × 工作日天数)
```

分子「实需人天」：每个作业现场按"同进同出（二、三级风险）、一般到位"管理要求占用
1 或 2 个人天，多日作业逐日累加；分母与班组成员/负责人承载力同构，为该单位
全部可用在册人员（Σβ，取自人员档案真实在册；无档案按 0、不瞎设默认）× 统计区间工作日天数。
适用范围与判定规则以业务口径确认单为准。

## 4. 周 / 月度 / 年度承载力聚合

> 分子按统计区间**全部自然日**叠加（周六日/法定节假日有计划的工时照计）。
> 分母仅按**工作日**叠加（剔除周末与法定节假日，config「非工作日」可调）。

```
F_k^负责人 = Σ(自然日 d) Σ(j=1..n_k)(T_j·θ_j·β_j) / [8 · Σ(工作日 d) Σ(i=1..N_k) β_i]
F_负责人   = max{ F_2, F_3, F_4, F_5 }

F_检修施工 = Σ(自然日 d) Σ(j=1..n){T_j·θ_j·Σβ_i} / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]
F_倒闸    = Σ(自然日 d) Σ(j=1..n)(T_j·Σβ_i)         / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]
F_巡视    = Σ(自然日 d) Σ(j=1..n)(T_j·Σβ_i)         / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]

班组聚合:max{F_负责人, F_检修施工} + F_巡视(按班组类型沿用日口径)
工区聚合:F_工区 = Σ k_i·F_i(与日口径一致)
```

周/月报告的图表柱高与评述段与上式同一套分子分母（不是有数据日的算术平均）：
单位图/评述为 Σ自然日日承载力% ÷ 工作日天数；管理图/评述为 Σ自然日实需 ÷ (在册 × 工作日天数)。
日报仍用当日值；矩阵表仍逐日列出。区间内无工作日（例如日报落在周六）时分母改用自然日天数，避免把当天有计划的承载力写成 0。

## 5. 分级预警管理(四级)

| 预警级别 | 轻载(蓝) | 适度(黄) | 重载(橙) | 满载(红) |
|---|---|---|---|---|
| 承载力区间 | ≤50% | 50%~75% | 75%~90% | >90% |

> 边界按**严格大于**命中上一档;承载力**可超 100%** 正常显示(>100% 落满载红,不设停工档)。警示函满载触发线 >90、提示函重载触发线 (75,90]。
