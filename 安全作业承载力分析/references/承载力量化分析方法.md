# 安全承载力量化分析方法(公式与口径)

> 依据《安全承载力量化分析方法》。承载力测算以"人"为承载基础、以"作业班组日承载力"为最小单元,综合考影响安全的各项要素加权赋值。
> 以工作负责人、班组成员承载力为首要判定条件,任一条件超红线时统筹调配作业计划;满足条件时再对班组、工区逐级量化评价。

## 1. 人员效能折算系数 β(单参数)

人员效能折算系数 β 为**单值参数**(每名人员一个 β 值),不按年龄、学历、技能、专家、能级、熟练度、素养、绩效分项折算。

> 人员档案为**必要数据源**(Excel 一律加载):各班组在册 Σβ、工作负责人真名、班组类型均取自此。β 由配置「强制统一β」在 `apply_formula_config` 之后、`parse_person` 时决定,不是把 1.0 写死在代码里。当前配置为 true:每人 β 用默认 **1.0**。改为 false 后读取人员档案「作业素养能力」(列映射到 `beta`),缺省才回退 1.0。多班组计划按班拆开计算:对不上档案的班组跳过,只有一个班组都对不上才整条不计算。以下公式中的 β 按这个开关取值。

| 项 | 取值 |
|---|---|
| β 来源 | true:配置「默认人员效能系数β」;false:人员档案「作业素养能力」 |
| 缺省 | 1.0(false 且字段缺失时) |
| 当前口径 | 「强制统一β」=true → 每人默认 1.0;置 false 后逐人读「作业素养能力」 |
| 人员档案 | 必要数据源,一律加载。未匹配班组跳过;整条计划仅在没有任何班组匹配时不计算 |

以下各承载力公式中的 β_j(作业负责人)、β_i(人员)一律取该单值参数。

## 2. 作业风险系数 θ

| 作业风险等级 | 二级 | 三级 | 四级 | 五级 | 装表接电 |
|---|---|---|---|---|---|
| θ | 1.5 | 1.2 | 1.0 | 0.8 | 0.2 |

`risk_theta` 的实际取值:

- 「工作内容」或「作业类型」去掉首尾空白后**正好是**「装表接电」时,不看作业风险等级,θ 取 `RISK_COEF`「装表接电」0.2。只是句子里含有「装表」、但不是这个完整词的,不按这条改判,也不改判成五级 0.8。
- 作业风险等级为空或「无」时 θ=0。
- 其余等级仍是二级 1.5、三级 1.2、四级 1.0、五级 0.8。未知等级回退四级 1.0。
- 「电网风险等级」不参与 θ。

## 3. 日承载力测算(标准工时 8 小时/天)

> 作业时长 T:不足 1 小时按 1 小时计,超过 8 小时按 8 小时计。

### 3.1 工作负责人承载力(k 级及以上风险)

```
F_k^负责人 = Σ(j=1..n_k)(T_j·θ_j·β_j) / [8 · Σ(i=1..N_k) β_i]
F_负责人 = max{ F_2, F_3, F_4, F_5 }
```

- n_k:当日 k 级及以上风险作业数量
- N_k:班组可承担 k 级及以上风险工作的负责人总数
- β_j:该项工作负责人的效能折算系数

### 3.2 班组成员承载力

通用分母:`8 · (该班组 Σβ − 当日不在岗 Σβ)`
不在岗只来自规范化 JSON 的 `absence`。Excel 路径固定传入空的请假列表,不会从 Excel 扣请假。JSON 里有请假/出差/参会/培训时,当日分母减去这些人的 β。

多班组计划不合并成一个分母。`iter_plan_team_slices` 按「班组名-人数」(分隔符为 、 ， , ; ； /)拆开:每个已匹配班组单独一条,人数用该班组名后的「-数字」,分母用该班组自己的 Σβ。对不上的班组跳过。整条计划的「工作负责人」数量只记在按出现顺序第一个匹配上的班组,其余拆分条为 0。

- **检修施工**(含人员档案班组类型为「调控」,以及没填或几种类型并列时回退的配置「默认班组类型」,当前为「检修施工」):`F = Σ(j=1..n){T_j·θ_j·Σ(i=1..m_j)β_i} / 分母`(m_j 为该班组这条计划上的人数)
- **倒闸操作(变电运维)**:`F = Σ(j=1..n){T_j·Σ(i=1..m_j)β_i} / 分母`
- **巡视类**:`F = Σ(j=1..n){T_j·Σ(i=1..m_j)β_i} / 分母`
- **调度、供服**:方法原文里的 `F = 当值操作/许可/报表等所需标准人工时 / 当值总人工时` **没有写进 `calculator.py`**。这两类不要按已实现口径引用。

### 3.3 班组日承载力

班组综合由人员信息「班组类型」决定,经 `PersonRecord.team_kind` 汇总到班组,再由 `_team_kind_for` 取用。没填或几种类型并列时回退配置「默认班组类型」(当前「检修施工」)。「调控」没有单独公式,走检修施工这一支。

| 班组类型 | 计算公式 |
|---|---|
| 检修施工(含调控、以及缺省/并列回退) | F = max{F_负责人, F_成员} |
| 运检合一 | F = max{F_负责人, F_成员} + F_巡视 |
| 变电运维 | F = F_操作 + F_巡视 |

### 3.4 工区(专业)承载力

```
F_工区 = Σ(i=1..N) k_i · F_i
k_i = F_i / Σ(i=1..N)F_i      (第 i 个班组权重为自身承载力占比)
```

### 3.5 管理承载力

```
F_管理 = 实需人天 / (单位全部在册可用人数 × 工作日天数)
```

分子「实需人天」：每个作业现场按"同进同出（二、三级风险）、一般到位"管理要求占用
1 或 2 个人天，多日作业逐日累加；分母与班组成员/负责人承载力同构，为该单位
全部可用在册人员（Σβ，取自人员档案真实在册；无档案按 0、不瞎设默认）× 统计区间工作日天数。
适用范围与判定规则以业务口径确认单为准。

## 4. 周 / 月度 / 年度承载力聚合

> 分子按统计区间**全部自然日**叠加（周六日/法定节假日有计划的工时照计）。
> 分母仅按**工作日**叠加（剔除周末与法定节假日，config「非工作日」可调）。

```
F_k^负责人 = Σ(自然日 d) Σ(j=1..n_k)(T_j·θ_j·β_j) / [8 · Σ(工作日 d) Σ(i=1..N_k) β_i]
F_负责人   = max{ F_2, F_3, F_4, F_5 }

F_检修施工 = Σ(自然日 d) Σ(j=1..n){T_j·θ_j·Σβ_i} / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]
F_倒闸    = Σ(自然日 d) Σ(j=1..n)(T_j·Σβ_i)         / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]
F_巡视    = Σ(自然日 d) Σ(j=1..n)(T_j·Σβ_i)         / [8 · Σ(工作日 d)(Σ(M)β − Σ(N)β)]

班组聚合:按该班组的班组类型沿用上一节日口径(检修施工=max(负责人,成员);运检合一再加巡视;变电运维=操作+巡视)。调度/供服公式不在 `calculator.py` 中。
工区聚合:F_工区 = Σ k_i·F_i(与日口径一致)
```

周/月报告的图表柱高与评述段与上式同一套分子分母（不是有数据日的算术平均）：
单位图/评述为 Σ自然日日承载力% ÷ 工作日天数；管理图/评述为 Σ自然日实需 ÷ (在册 × 工作日天数)。
日报仍用当日值；矩阵表仍逐日列出。区间内无工作日（例如日报落在周六）时分母改用自然日天数，避免把当天有计划的承载力写成 0。

## 5. 分级预警管理(四级)

| 预警级别 | 轻载(蓝) | 适度(黄) | 重载(橙) | 满载(红) |
|---|---|---|---|---|
| 承载力区间 | ≤50% | 50%~75% | 75%~90% | >90% |

> 边界按**严格大于**命中上一档;承载力**可超 100%** 正常显示(>100% 落满载红,不设停工档)。警示函满载触发线 >90、提示函重载触发线 (75,90]。
